# 🎉 第二阶段：用户认证与权限控制系统 - 开发完成！

## ✅ 已完成所有需求

### 1. 安全性增强 ✅
- ✅ 使用 `passlib[bcrypt]` 实现密码哈希加密与校验
- ✅ 使用 `python-jose[cryptography]` 实现 JWT Token 生成与解码
- ✅ 密码不存储明文，使用 bcrypt 加盐哈希

### 2. 登录功能 ✅
- ✅ `/api/v1/auth/login` 接口
- ✅ 接收学号（student_id）和密码
- ✅ 返回 JWT Token
- ✅ Payload 包含：`sub`(用户ID)、`role`(角色)、`student_id`(学号)

### 3. 身份验证依赖项 ✅
- ✅ `get_current_user()` - 从 Authorization 提取并验证 Token
- ✅ Token 无效或过期自动抛出 401 异常
- ✅ `get_current_active_user()` - 验证用户状态

### 4. 角色权限拦截 (RBAC) ✅
- ✅ `RoleChecker` 类 - 灵活的角色检查器
- ✅ 支持多种角色组合
- ✅ 便捷实例：`require_member`、`require_admin`

**使用示例：**
```python
# 仅 Admin
Depends(RoleChecker(["admin"]))
Depends(require_admin)

# Member 或 Admin
Depends(RoleChecker(["member", "admin"]))
Depends(require_member)

# 自定义组合
Depends(RoleChecker(["visitor", "member"]))
```

### 5. 代码示例（三个场景）✅

#### 场景 A（公开）- 提交报名表单
```python
@router.post("/apply")
async def submit_application(...):
    """
    场景 A（公开）：提交报名表单
    
    **无需登录** - 游客也可以报名
    """
```

#### 场景 B（内部）- 预约会议室
```python
@router.post("/create")
async def create_booking(
    current_user: User = Depends(require_member)  # Member 或 Admin
):
    """
    场景 B（内部）：预约会议室
    
    **需要 Member 或 Admin 权限**
    """
```

#### 场景 C（管理）- 重置他人密码
```python
@router.post("/reset-password")
async def reset_user_password(
    current_user: User = Depends(require_admin)  # 仅 Admin
):
    """
    场景 C（管理）：重置他人密码
    
    **仅限 Admin 权限**
    """
```

### 6. 统一返回格式 ✅

**成功响应：**
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {...}
}
```

**错误响应：**
```json
{
  "code": 401,
  "msg": "无效的认证凭据或 Token 已过期",
  "data": null
}
```

**常见错误码：**
- `401` - Token 无效或过期
- `403` - 权限不足或账号未激活
- `404` - 资源不存在
- `500` - 服务器内部错误

## 🚀 快速开始

### 1. 启动应用
```bash
python main.py
```

应用将在 http://localhost:8000 启动

### 2. 访问 API 文档
浏览器打开：http://localhost:8000/docs

你会看到 Swagger UI 交互式文档

### 3. 测试登录

**方式一：使用 Swagger UI**
1. 打开 http://localhost:8000/docs
2. 找到 `🔐 认证` -> `POST /api/v1/auth/login`
3. 点击 "Try it out"
4. 输入：
   ```json
   {
     "student_id": "admin",
     "password": "123456"
   }
   ```
5. 点击 "Execute"
6. 复制返回的 `access_token`

**方式二：使用 curl**
```bash
curl -X POST "http://localhost:8000/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "student_id": "admin",
    "password": "123456"
  }'
```

### 4. 使用 Token 访问受保护接口

**在 Swagger UI 中：**
1. 点击右上角 **Authorize** 按钮（锁图标）
2. 输入：`Bearer <your_access_token>`
3. 点击 **Authorize**
4. 现在可以访问需要权限的接口了

**使用 curl：**
```bash
curl -X GET "http://localhost:8000/api/v1/auth/me" \
  -H "Authorization: Bearer <your_access_token>"
```

### 5. 运行自动化测试

```bash
# 确保应用正在运行
# 在另一个终端执行：
pip install requests
python test_auth.py
```

## 📝 核心文件说明

### 安全核心
- **`app/core/security.py`** - JWT 和密码加密的核心实现
  - `get_password_hash()` - 生成密码哈希
  - `verify_password()` - 验证密码
  - `create_access_token()` - 生成 JWT Token
  - `decode_access_token()` - 解码并验证 Token

### 权限控制
- **`app/core/dependencies.py`** - RBAC 权限控制
  - `get_current_user()` - 获取当前用户（验证 Token）
  - `get_current_active_user()` - 获取激活用户
  - `RoleChecker` - 灵活的角色检查器
  - `require_member` - Member 或 Admin
  - `require_admin` - 仅 Admin

### 数据模型
- **`app/schemas/response.py`** - 统一响应格式
- **`app/schemas/auth.py`** - 认证相关的 Pydantic 模型

### API 路由
- **`app/api/v1/auth.py`** - 认证路由（登录、注册、修改密码）
- **`app/api/v1/signups.py`** - 报名系统（场景 A：公开）
- **`app/api/v1/bookings.py`** - 会议室预约（场景 B+C）

### 主应用
- **`app/main.py`** - FastAPI 应用入口，集成所有路由

## 🎯 API 接口总览

### 🔐 认证接口
- `POST /api/v1/auth/login` - 登录
- `POST /api/v1/auth/register` - 注册
- `GET /api/v1/auth/me` - 获取当前用户信息
- `PUT /api/v1/auth/password` - 修改密码
- `POST /api/v1/auth/reset-password` 🔒 - 重置他人密码（Admin）
- `POST /api/v1/auth/approve/{user_id}` 🔒 - 审核用户（Admin）

### 📝 报名系统（公开）
- `GET /api/v1/signups/configs` ✅ - 获取活动列表（公开）
- `POST /api/v1/signups/apply` ✅ - 提交报名（公开）
- `GET /api/v1/signups/applications` 🔒 - 查看报名（Admin）

### 🏢 会议室预约
- `POST /api/v1/bookings/create` 🔐 - 预约会议室（Member+）
- `GET /api/v1/bookings/my-bookings` 🔐 - 我的预约（Member+）
- `POST /api/v1/bookings/approve/{id}` 🔒 - 审批预约（Admin）
- `GET /api/v1/bookings/all` 🔒 - 所有预约（Admin）

**图例：**
- ✅ 公开 - 无需登录
- 🔐 Member+ - 需要 Member 或 Admin
- 🔒 Admin - 仅限 Admin
