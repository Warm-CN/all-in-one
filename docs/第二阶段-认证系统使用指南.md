# 第二阶段：用户认证与权限控制系统 - 使用指南

## 🎯 功能概览

已完成第二阶段开发，实现了完整的 **JWT 认证** 和 **RBAC 权限控制**系统。

### ✅ 核心功能

1. **密码安全**：使用 bcrypt 算法加密存储
2. **JWT Token**：使用 python-jose 生成和验证 Token
3. **身份验证**：`get_current_user` 依赖项自动验证 Token
4. **灵活的角色权限**：`RoleChecker` 支持多角色组合
5. **统一响应格式**：所有接口返回 `{code, msg, data}` 格式
6. **速率限制**：使用 slowapi 防止暴力破解（登录 5次/分钟，注册 3次/分钟）

## 🔐 核心模块说明

### 1. 安全核心 (`app/core/security.py`)

```python
# 密码加密
hashed = get_password_hash("123456")

# 密码验证
is_valid = verify_password("123456", hashed)

# 生成 JWT Token
token = create_access_token(data={
    "sub": "1",           # 用户ID
    "role": "admin",      # 角色
    "student_id": "admin" # 学号（可选）
})

# 解码 Token
payload = decode_access_token(token)
# 返回: {"sub": "1", "role": "admin", "exp": 1234567890, ...}
```

### 2. 权限依赖 (`app/core/dependencies.py`)

```python
from app.core.dependencies import (
    get_current_user,          # 获取当前用户（验证 Token）
    get_current_active_user,   # 获取激活的用户
    RoleChecker,               # 灵活的角色检查器
    require_member,            # Member 或 Admin
    require_admin              # 仅 Admin
)

# 使用示例
@router.get("/protected")
async def protected_route(
    current_user: User = Depends(get_current_active_user)
):
    return {"user": current_user.full_name}

@router.get("/admin-only")
async def admin_route(
    current_user: User = Depends(require_admin)
):
    return {"msg": "只有管理员能看到"}

# 自定义角色组合
@router.get("/custom")
async def custom_route(
    current_user: User = Depends(RoleChecker(["member", "admin"]))
):
    return {"msg": "Member 和 Admin 都可以访问"}
```

## 📝 API 接口文档

### 认证接口 (`/api/v1/auth`)

#### 1. 登录 `POST /api/v1/auth/login`

**请求体：**
```json
{
  "student_id": "admin",
  "password": "123456"
}
```

**成功响应：**
```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "token": {
      "access_token": "eyJhbGc...",
      "token_type": "bearer",
      "expires_in": 86400
    },
    "user": {
      "id": 1,
      "full_name": "系统管理员",
      "student_id": "admin",
      "role": "admin",
      "status": "active"
    }
  }
}
```

**错误响应：**
```json
{
  "code": 401,
  "msg": "学号或密码错误",
  "data": null
}
```

#### 2. 注册 `POST /api/v1/auth/register`

**请求体：**
```json
{
  "full_name": "张三",
  "student_id": "2021001",
  "password": "password123",
  "phone": "13800138001",
  "email": "zhangsan@example.com",
  "department": "技术部"
}
```

**响应：** 注册成功后状态为 `PENDING`，需要管理员审核。

#### 3. 获取当前用户信息 `GET /api/v1/auth/me`

**请求头：**
```
Authorization: Bearer <access_token>
```

**响应：**
```json
{
  "code": 200,
  "msg": "获取成功",
  "data": {
    "id": 1,
    "full_name": "系统管理员",
    "student_id": "admin",
    "role": "admin",
    "status": "active"
  }
}
```

#### 4. 修改密码 `PUT /api/v1/auth/password`

需要提供旧密码和新密码。

#### 5. 重置他人密码 `POST /api/v1/auth/reset-password` 🔒 Admin Only

**场景 C：** 仅管理员可以重置他人密码。

### 场景 A：公开接口 - 报名系统 (`/api/v1/signups`)

#### 1. 获取活动列表 `GET /api/v1/signups/configs` ✅ 公开

**无需登录**，任何人都可以查看当前可报名的活动。

#### 2. 提交报名 `POST /api/v1/signups/apply` ✅ 公开

**请求体：**
```json

  "signup_config_id": 1,
  "student_id": "2021001",
  "form_data": {
    "姓名": "张三",
    "专业": "计算机科学",
    "自我介绍": "我热爱编程..."
  }
}
```

#### 3. 查看所有报名 `GET /api/v1/signups/applications` 🔒 Admin Only

**场景 C：** 管理员导出报名数据。

---

### 场景 B：内部接口 - 会议室预约 (`/api/bookings`)

#### 1. 获取预约列表 `GET /api/bookings?date=YYYY-MM-DD`

获取指定日期的所有预约记录。

#### 2. 提交预约 `POST /api/bookings` 🔐 需登录

**请求体：**
```json
{
  "booking_date": "2026-01-20",
  "start_time": "14:00",
  "end_time": "16:00",
  "num_people": 20,
  "remarks": "需要投影仪"
}
```

#### 3. 取消预约 `DELETE /api/bookings/{id}` 🔐 需登录

普通用户只能删除自己的预约，管理员可删除任意预约。

#### 4. 查看我的预约 `GET /api/bookings/my`

查看自己的预约记录，支持 `upcoming=true` 参数筛选未来预约。

## 🎨 权限控制示例

```python
from fastapi import APIRouter, Depends
from app.core.dependencies import RoleChecker, require_member, require_admin
from app.models.user import User

router = APIRouter()

# 场景 A：公开接口（无需登录）
@router.get("/public")
async def public_endpoint():
    return {"msg": "任何人都可以访问"}

# 场景 B：内部接口（Member 或 Admin）
@router.get("/internal")
async def internal_endpoint(
    current_user: User = Depends(require_member)
):
    return {"msg": f"欢迎，{current_user.full_name}"}

# 场景 C：管理接口（仅 Admin）
@router.get("/admin")
async def admin_endpoint(
    current_user: User = Depends(require_admin)
):
    return {"msg": "管理员专属"}

# 自定义角色组合
@router.get("/custom")
async def custom_endpoint(
    current_user: User = Depends(RoleChecker(["visitor", "member"]))
):
    return {"msg": "Visitor 和 Member 可以访问，Admin 不行"}
```

## 🔒 安全特性

1. **密码加密**：使用 bcrypt 算法，加盐哈希存储
2. **Token 过期**：默认 24 小时过期（可配置）
3. **Token 签名**：使用 HS256 算法签名，防止篡改
4. **角色验证**：每个请求自动验证用户角色
5. **状态检查**：自动验证用户是否为 ACTIVE 状态
6. **速率限制**：基于客户端 IP 限制请求频率，防止暴力破解
   - 登录接口：5 次/分钟
   - 注册接口：3 次/分钟
   - 超出限制返回 HTTP 429
7. **配置校验**：启动时校验 `SECRET_KEY` 和 `DB_PASSWORD`，拒绝使用不安全的默认值
