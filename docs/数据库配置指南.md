# 数据库与环境变量配置指南

## 一、安装 MySQL

### Windows
1. 下载 [MySQL 8.x Installer](https://dev.mysql.com/downloads/installer/)，选择 Server only
2. 安装时设置 root 密码（记住这个密码，后面要填到 `.env`）
3. 安装完成后 MySQL 服务会自动启动，默认端口 `3306`

### 验证安装
```powershell
mysql -u root -p
```
输入密码后能进入 MySQL 命令行即安装成功。

## 二、创建数据库

登录 MySQL 后执行：
```sql
CREATE DATABASE club_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

> `utf8mb4` 是必须的，系统包含中文内容和 emoji，不能用 `utf8`（它只支持 3 字节）。

## 三、配置 .env 文件

在项目根目录创建 `.env` 文件，内容如下：

```env
# ========== 数据库配置 ==========
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=club_management
DB_ECHO=False

# ========== JWT 配置 ==========
SECRET_KEY=运行下方命令生成的随机字符串
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440

# ========== 应用配置 ==========
DEBUG=True
APP_NAME=社团统一管理系统
APP_VERSION=1.0.0

# ========== CORS 跨域配置 ==========
BACKEND_CORS_ORIGINS=http://localhost:3000,http://localhost:8080
```

## 四、各字段说明

### 数据库相关

| 字段 | 说明 | 示例 |
|------|------|------|
| `DB_HOST` | MySQL 服务器地址，本地开发填 `localhost` | `localhost` |
| `DB_PORT` | MySQL 端口，默认 `3306` | `3306` |
| `DB_USER` | 数据库用户名，开发环境通常用 `root` | `root` |
| `DB_PASSWORD` | 数据库密码，**必填**，不能为空 | `your_password` |
| `DB_NAME` | 数据库名，需与第二步创建的一致 | `club_management` |
| `DB_ECHO` | 是否打印 SQL 语句（调试用），生产环境设 `False` | `False` |

### JWT 相关

| 字段 | 说明 | 示例 |
|------|------|------|
| `SECRET_KEY` | JWT 签名密钥，**必填**，不能为空或默认值 | 随机 64 位字符串 |
| `ALGORITHM` | 签名算法，默认 `HS256` | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Token 过期时间（分钟），`1440` = 24 小时 | `1440` |

### 应用相关

| 字段 | 说明 | 示例 |
|------|------|------|
| `DEBUG` | 调试模式，开发时设 `True`，生产环境设 `False` | `True` |
| `APP_NAME` | 应用名称 | `社团统一管理系统` |
| `APP_VERSION` | 版本号 | `1.0.0` |

### CORS 相关

| 字段 | 说明 | 示例 |
|------|------|------|
| `BACKEND_CORS_ORIGINS` | 允许跨域访问的前端地址，逗号分隔 | `http://localhost:3000` |

## 五、生成 SECRET_KEY

打开 PowerShell 执行：
```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

将输出的 64 位字符串填入 `.env` 的 `SECRET_KEY=` 后面。

## 六、初始化数据库表

配置好 `.env` 后，后端首次启动时会自动建表（SQLAlchemy `create_all`）。

也可以手动执行：
```powershell
python -c "from app.core.database import engine, Base; from app.models import *; Base.metadata.create_all(engine)"
```

## 七、创建管理员账号

建表后执行：
```powershell
python scripts/init_admin.py
```

默认管理员：

| 字段 | 值 |
|------|-----|
| 学号 | `110` |
| 密码 | `654321` |

## 八、生产环境注意事项

- `DEBUG` 设为 `False`
- `SECRET_KEY` 不要用开发环境的值，重新生成一个
- `DB_USER` 建议创建专用用户，不要用 root
- `BACKEND_CORS_ORIGINS` 只填实际前端域名
- `.env` 文件不要提交到 Git（已在 `.gitignore` 中忽略）
