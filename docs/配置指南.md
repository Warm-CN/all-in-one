# 社团统一管理系统 - 配置指南

## 项目概述

这是一个基于 FastAPI + Vue 3 的社团统一管理系统，支持用户认证、RBAC 权限控制、会议室预约、报名系统、日程管理等功能。

- **后端**: FastAPI + SQLAlchemy + MySQL
- **前端**: Vue 3 + Element Plus + Tailwind CSS + Vite

---

## 环境要求

### 后端环境
- Python 3.8+
- MySQL 5.7+ / 8.0+

### 前端环境
- Node.js 16+
- npm 或 yarn

## 一、后端配置

### 1.1 安装 Python 依赖

在项目根目录下执行：

```bash
pip install -r requirements.txt
```

主要依赖包括：
- `fastapi` - Web 框架
- `uvicorn` - ASGI 服务器
- `sqlalchemy` - ORM
- `pymysql` - MySQL 驱动
- `alembic` - 数据库迁移工具
- `python-jose` - JWT 认证
- `passlib` - 密码加密

### 1.2 配置环境变量

复制 `.env.example` 文件为 `.env`：

```bash
cp .env.example .env
```

编辑 `.env` 文件，修改以下配置：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password_here    # 修改为你的 MySQL 密码
DB_NAME=club_management
DB_ECHO=False

# JWT 配置
SECRET_KEY=your-secret-key-change-in-production-use-openssl-rand-hex-32
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440

# 应用配置
DEBUG=True
APP_NAME=社团统一管理系统
APP_VERSION=1.0.0

# CORS 配置 (多个源用逗号分隔)
BACKEND_CORS_ORIGINS=http://localhost:3000,http://localhost:8080
```


### 1.3 配置和初始化数据库

#### 创建数据库

在 MySQL 中执行：

```sql
CREATE DATABASE club_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 数据库迁移（可选）

如果使用 Alembic 进行数据库迁移：

```bash
# 初始化 Alembic（首次使用）
alembic init alembic

# 生成迁移脚本
alembic revision --autogenerate -m "Initial migration"

# 执行迁移
alembic upgrade head
```

#### 自动创建表（推荐方式）

项目已配置启动时自动创建表，直接启动后端即可自动创建所有数据表：

```bash
python -m uvicorn app.main:app --reload
```

### 1.4 启动后端服务

#### 开发模式（自动重载）

直接运行`main.py`文件

或者使用命令行：
```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

#### 生产模式

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

启动成功后，可以访问：
- API 文档: http://localhost:8000/docs
- ReDoc 文档: http://localhost:8000/redoc
- 健康检查: http://localhost:8000/health

## 二、前端配置

### 2.1 安装 Node.js 依赖

进入 `frontend` 目录：

```bash
cd frontend
npm install
```

主要依赖包括：
- `vue` - 前端框架
- `vue-router` - 路由
- `pinia` - 状态管理
- `element-plus` - UI 组件库
- `axios` - HTTP 客户端
- `tailwindcss` - CSS 框架

### 2.2 配置环境变量

编辑 `frontend/.env` 文件（如果不存在则创建）：

```env
# API 基础地址
VITE_API_BASE_URL=http://localhost:8000
```

### 2.3 启动前端服务

#### 开发模式

在 `frontend` 目录下执行：

```bash
npm run dev
```

默认运行在 http://localhost:5173

#### 构建生产版本

```bash
npm run build
```

构建产物在 `frontend/dist` 目录。

#### 预览生产版本

```bash
npm run preview
```

## 四、常见问题

### 4.1 数据库连接失败

- 检查 MySQL 服务是否启动
- 确认 `.env` 中的数据库配置是否正确
- 确认数据库用户有足够权限

### 4.2 CORS 跨域问题

检查 `.env` 中的 `BACKEND_CORS_ORIGINS` 是否包含前端地址。

### 4.3 前端无法请求后端 API

确认 `frontend/.env` 中的 `VITE_API_BASE_URL` 指向正确的后端地址。

## 五、功能模块

| 模块 | 路由前缀 | 说明 |
|------|----------|------|
| 认证 | `/api/v1/auth` | 登录、注册、Token 刷新 |
| 报名系统 | `/api/v1/signups` | 公开报名接口 |
| 会议室预约 | `/api/bookings` | 日常预约（无需审批，最多7天内） |
| 管理员-用户管理 | `/api/v1/admin/users` | 用户管理 |
| 管理员-会议室管理 | `/api/v1/admin/bookings` | 会议室预约管理 |
| 通讯录 | `/api/v1/users` | 用户查询 |
| 日程查询 | `/api/v1/schedules` | 日程查询（支持单日/范围查询） |
| 管理员-日程管理 | `/api/v1/admin/schedules` | 日程管理（创建/删除/冲突检测） |
