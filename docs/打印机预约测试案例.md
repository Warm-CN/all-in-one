# 拓竹杯打印机预约：实施与验收

## 阅读结论与实施计划

基线：远程 `origin/ZHM` 的 `c153cd5`。项目使用 FastAPI + SQLAlchemy + MySQL、Vue 3 + Element Plus + Tailwind；公开页面 `/team-portal` 和 `/apply` 使用蓝绿浅色渐变、圆角卡片和分段导航。

1. 新增公开 `/printer-booking` 和登录管理员页面，复用现有视觉语言，支持桌面和手机。
2. 使用独立的新表维护三台机器、专属队伍、预约和异常。增量初始化不得删除旧表或重建原数据库。
3. 队伍自主选择时间。预约区间按 `[开始, 结束)` 判定，同机不能重叠，异机互不影响；机器行锁串行化同机写入。
4. 自助登记使用管理员邀请码，队伍另设独立口令；验证队长学号、手机号和独立口令后取得专用会话。公开日程不返回手机号、学号和口令。
5. 记录实际签到与归还，异常关联上一条实际使用记录，保存历史队伍快照。未使用和取消的预约不进入追溯链。异常关联用于追溯，由管理员记录处理结果。
6. 北京时间处理预约。办公室开始时间约束由管理员配置；未提供具体办公时间，默认关闭，启用后只限制开始时间，结束可跨越办公时段。
7. 独立本地测试数据库验证接口、并发及生产构建；提供手动云端增量初始化、SCP 静态文件和后端拉取部署说明。

## 测试案例

| 编号 | 场景与操作 | 期望 |
|---|---|---|
| P01 | 重复执行初始化脚本 | 三台机器，不重复插入，保留原数据 |
| P02 | 正确邀请码登记队伍，核验队长信息与独立口令 | 返回专用会话和本队预约 |
| P03 | 错误邀请码/错误口令/错误手机号 | 拒绝，不泄露其他队伍信息 |
| P04 | 未认证创建、取消、签到、归还或报告异常 | 拒绝 |
| P05 | 队伍 A 操作队伍 B 的预约 | 拒绝 |
| P06 | 分别在三台机预约有效未来时间段 | 三条成功，各机独立 |
| P07 | 同机预约部分重叠、完全相同、包含或被包含 | 全部拒绝 |
| P08 | 同机前条结束恰好等于后条开始 | 允许 |
| P09 | 异机同一时间段 | 允许 |
| P10 | 两个独立数据库会话并发抢同机同一段 | 仅一个成功，库中仅一条有效预约 |
| P11 | 结束不晚于开始、过去时间、缺字段或非法时间 | 拒绝并返回可读错误 |
| P12 | 取消未开始预约后重新预约该时间 | 允许，保留取消历史 |
| P13 | 非预约时间签到、重复签到、未签到归还 | 按使用状态拒绝非法操作 |
| P14 | 同机已有未归还使用记录时另一队签到 | 拒绝并提示交接 |
| P15 | A 实际使用并归还，B 使用前报告异常 | 异常关联 A 的使用记录及队伍快照 |
| P16 | 无历史使用、存在取消/未使用/未来预约时报告异常 | 不误认这些预约为上一使用队伍 |
| P17 | 已记录异常后修改队伍名称或新增预约 | 原追溯记录保持稳定 |
| P18 | 管理员停机、普通队伍预约该机、管理员恢复 | 停机时拒绝，恢复后允许 |
| P19 | 未登录或普通社团用户访问管理 API | 拒绝 |
| P20 | 启用办公时间，测试开门、关门和非办公日开始 | 开始按配置边界校验 |
| P21 | 开放时间内开始，结束在关门后或次日 | 允许（仍须无冲突） |
| P22 | 关闭办公开始限制 | 允许原本不在办公时间的未来开始 |
| P23 | 时间带 +08:00 和等效 UTC 输入 | 转换后一致，跨日查询包含跨日预约 |
| P24 | 管理员查看并处理异常 | 保存处理意见及状态 |
| P25 | 桌面及窄屏访问、切日期、空列表、网络失败、重复点提交 | 布局可用，错误可见，操作有加载反馈 |
| P26 | 前端生产构建并访问公开深层路径 | 构建成功，路由和 API 地址正确 |

实际执行命令、通过数量和限制见部署文档的本地验证记录；本表是验收范围，不能视为全部已经通过。
