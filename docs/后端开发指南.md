# 社团统一管理系统 - 后端开发指南

## 项目简介

这是一个基于 FastAPI + SQLAlchemy 的社团统一管理系统后端，支持用户认证、RBAC 权限控制、会议室预约、报名系统等功能。

## 功能特性

### 后端核心数据模型
- **Users, Rooms, Bookings, SignupConfigs, Applications** - SQLAlchemy 数据模型
- **完善的用户认证系统** - 基于 python-jose 的 JWT Token 认证

### 后端核心功能
- **认证** - 使用 passlib[bcrypt] 进行密码加密
- **权限管理** - 基于角色的访问控制，包含 Visitor, Member, Admin 三种角色
- **统一响应格式** - 使用 `{code, msg, data}` 统一接口响应
- **权限装饰器** - 包含三种权限控制:
  - **权限 A: 登录用户权限** - 普通登录用户 - 测试用户
  - **权限 B: 审批用户权限** - 通过注册的用户 - Member/Admin
  - **权限 C: 管理员权限** - 招报配置、通过审核 - Admin

## 数据库数据模型

### 1. 用户模型 (users)
- 角色类型: Visitor（未认证）、Member（已激活）、Admin（管理员角色）
- 用户状态: `pending`（待审核）、`active`（激活可用）、`inactive`（停用用户）
- 字段: `id, username, password_hash, real_name, student_id, phone, role, status, email, avatar`

### 2. 会议室模型 (rooms)
- 字段: `id, name, location, capacity, equipment, is_available, description, image_url`

### 3. 会议室预约模型 (bookings)
- 预约状态: `pending, approved, rejected, cancelled, completed`
- 字段: `id, user_id, room_id, start_time, end_time, purpose, status, participant_count, notes, reject_reason`

### 4. 招报配置模型 (signup_configs)
- 存储各活动模块的自定义报名表单配置 - JSON 字段
- 字段: `id, title, description, start_time, end_time, max_participants, is_active, form_fields, category`

### 5. 报名模型 (applications)
- 用户提交的报名信息数据 - JSON 字段
- 报名状态: `submitted, reviewing, accepted, rejected, cancelled`
- 字段: `id, user_id, signup_config_id, form_data, status, review_notes`

## 快速开始

### 1. 环境准备

```bash
# 克隆项目仓库
git clone <repository-url>
cd all_in_one

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
# 复制示例环境变量文件
copy .env.example .env

# 编辑 .env 文件配置数据库密码
# DB_PASSWORD=`你的MySQL密码`
```

### 3. 初始化数据库

```bash
# 在 MySQL 中创建数据库
mysql -u root -p
CREATE DATABASE club_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
exit;

# 运行初始化脚本（默认创建管理员账户）
python init_db.py
```

默认管理员账户:
- 用户名: `admin`
- 密码: `123456`

### 4. 启动应用

```bash
python main.py
```

访问 http://localhost:8000/docs 查看 **交互式 API 文档**

### 5. 测试认证功能

```bash
# 启动应用后在另一个终端运行测试
pip install requests
python test_auth.py
```

## 核心 API 端点

### 认证接口 (`/api/v1/auth`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/login` | POST | 公开 | 用户登录 |
| `/register` | POST | 公开 | 用户注册申请 |
| `/me` | GET | 需认证 | 获取当前用户资料信息 |
| `/password` | PUT | 需认证 | 修改自己密码 |
| `/reset-password` | POST | Admin | 重置用户密码 |
| `/approve/{user_id}` | POST | Admin | 审核通过用户 |

### 报名管理 (`/api/v1/signups`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/configs` | GET | **公开** | 获取活动报名配置列表 |
| `/apply` | POST | **公开** | 提交报名、已登录用户 |
| `/applications` | GET | Admin | 查看收到的报名 |

### 会议室预约 (`/api/v1/bookings`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/create` | POST | Member+ | 创建预约会议室 |
| `/my-bookings` | GET | Member+ | 查看我的预约 |
| `/approve/{id}` | POST | Admin | 审核通过预约 |
| `/all` | GET | Admin | 查看所有预约 |

详细接口文档见 [docs/后端-认证系统使用指南.md](docs/后端-认证系统使用指南.md)

## 业务模块扩展

目前系统预留了三个业务模块目录:

1. **招新模块** (`app/modules/recruitment/`)
   - 用于招新报名、审核流程

2. **无线杯模块** (`app/modules/wireless_cup/`)
   - 用于无线杯比赛报名、数据统计

3. **电信杯模块** (`app/modules/telecom_cup/`)
   - 用于电信杯比赛报名、数据统计

每个模块包含:
- `routes.py` - 路由定义
- `schemas.py` - 数据模式定义
- `services.py` - 业务逻辑
- `crud.py` - 数据库操作

### 权限控制示例

```python
from fastapi import APIRouter, Depends
from app.core.dependencies import require_member, require_admin

router = APIRouter()

@router.get("/member-only")
async def member_only_route(current_user = Depends(require_member)):
    return {"message": "仅 Member 可访问此接口"}

@router.get("/admin-only")
async def admin_only_route(current_user = Depends(require_admin)):
    return {"message": "仅 Admin 可访问此接口"}
```

## 核心技术栈

- **Web框架**: FastAPI 0.109.0
- **ORM**: SQLAlchemy 2.0.25
- **数据库**: MySQL（推荐 PyMySQL）
- **身份认证**: JWT (python-jose)
- **密码加密**: Passlib (bcrypt)
- **数据验证**: Pydantic
- **数据库迁移**: Alembic
- **ASGI 服务器**: Uvicorn
