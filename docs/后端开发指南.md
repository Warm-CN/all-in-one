# 社团统一管理系统 - 后端开发指南

## 项目简介

这是一个基于 FastAPI + SQLAlchemy 的社团统一管理系统后端，支持用户认证、RBAC 权限控制、会议室预约、报名系统等功能。

## 功能特性

### 后端核心数据模型
- **Users, Rooms, Bookings, SignupConfigs, Applications** - SQLAlchemy 数据模型
- **完善的用户认证系统** - 基于 python-jose 的 JWT Token 认证

### 后端核心功能
- **认证** - 使用 passlib[bcrypt] 进行密码加密
- **权限管理** - 基于角色的访问控制，包含 Member, Admin 两种角色
- **速率限制** - 使用 slowapi 进行 API 速率限制（防暴力破解）
- **统一响应格式** - 使用 `{code, msg, data}` 统一接口响应
- **权限装饰器** - 包含三种权限控制:
  - **权限 A: 登录用户权限** - 普通登录用户 - 测试用户
  - **权限 B: 审批用户权限** - 通过注册的用户 - Member/Admin
  - **权限 C: 管理员权限** - 招报配置、通过审核 - Admin

## 数据库数据模型

### 1. 用户模型 (users)
- 角色类型: Member（普通成员）、Admin（管理员）
- 用户状态: `pending`（待审核）、`active`（激活可用）、`rejected`（拒绝）、`disabled`（停用）
- 字段: `id, student_id, password_hash, full_name, phone, email, department, position, role, status`

### 2. 会议室预约模型 (room_bookings)
- 简化版预约模型，无需审批流程
- 字段: `id, user_id, booking_date, start_time, end_time, num_people, remarks`
- 关系: 关联 users 表（user）
- 约束: 预约日期不能超过未来7天，同一日期的时间段不能重叠

### 3. 日程模型 (schedules)
- 用于社团活动日程管理
- 字段: `id, title, schedule_date, start_time, end_time, location, color`
- 功能: 支持时间冲突检测（但不阻止创建）

### 4. 招报配置模型 (signup_configs)
- 存储各活动模块的自定义报名表单配置 - JSON 字段
- 字段: `id, title, description, start_time, end_time, max_participants, is_active, form_fields, category`

### 5. 报名模型 (applications)
- 用户提交的报名信息数据 - JSON 字段
- 报名状态: `submitted, reviewing, accepted, rejected, cancelled`
- 字段: `id, user_id, signup_config_id, form_data, status, review_notes`

### 6. 竞赛队伍模型 (teams)
- 竞赛队伍管理，支持多比赛隔离
- 字段: `id, name, competition_event_id, captain_id, status, topic_option_id, ...`

### 7. 比赛事件模型 (competition_events)
- 存储比赛/竞赛的基本信息
- 字段: `id, name, description, start_time, end_time, status, ...`

### 8. 队伍成员模型 (team_members)
- 队伍与用户的关联关系
- 字段: `id, team_id, user_id, role`

## 快速开始

### 1. 环境准备

```bash
# 克隆项目仓库
git clone git@github.com:Warm-CN/all-in-one.git
cd all-in-one

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
# 复制示例环境变量文件
copy .env.example .env

# 编辑 .env 文件配置数据库密码
# DB_PASSWORD=`你的MySQL密码`
```

### 3. 初始化数据库

```bash
# 在 MySQL 中创建数据库
mysql -u root -p
CREATE DATABASE club_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
exit;

# 运行初始化脚本（默认创建管理员账户）
python init_db.py
```

默认管理员账户:
- 用户名: `110`
- 密码: `654321`

### 4. 启动应用

```bash
python main.py
```

访问 http://localhost:8001/docs 查看 **交互式 API 文档**

### 5. 测试认证功能

```bash
# 启动应用后在另一个终端运行测试
pip install requests
python test_auth.py
```

## 核心 API 端点

### 认证接口 (`/api/v1/auth`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/login` | POST | 公开 | 用户登录 |
| `/register` | POST | 公开 | 用户注册申请 |
| `/me` | GET | 需认证 | 获取当前用户资料信息 |
| `/password` | PUT | 需认证 | 修改自己密码 |
| `/reset-password` | POST | Admin | 重置用户密码 |
| `/approve/{user_id}` | POST | Admin | 审核通过用户 |

### 报名管理 (`/api/v1/signups`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/configs` | GET | **公开** | 获取活动报名配置列表 |
| `/apply` | POST | **公开** | 提交报名、已登录用户 |
| `/applications` | GET | Admin | 查看收到的报名 |

### 会议室预约 (`/api/bookings`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | GET | 需认证 | 获取指定日期的预约列表 |
| `/` | POST | 需认证 | 提交会议室预约（最多7天内） |
| `/{id}` | DELETE | 需认证 | 取消预约 |
| `/my` | GET | 需认证 | 获取我的预约（支持 upcoming 参数） |

### 日程查询 (`/api/v1/schedules`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | GET | 需认证 | 获取日程列表（支持单日/范围查询） |

### 管理员-日程管理 (`/api/v1/admin/schedules`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | POST | Admin | 创建日程 |
| `/{schedule_id}` | DELETE | Admin | 删除日程 |
| `/check-overlap` | GET | Admin | 检查时间冲突 |

### 管理员-会议室管理 (`/api/v1/admin/bookings`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | GET | Admin | 获取所有预约记录 |
| `/{id}` | DELETE | Admin | 删除任意预约 |

### 通讯录 (`/api/v1/users`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | GET | 需认证 | 获取用户列表（支持搜索） |

### 管理员-用户管理 (`/api/v1/admin/users`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | GET | Admin | 获取所有用户 |
| `/{user_id}` | PUT | Admin | 更新用户信息 |
| `/{user_id}` | DELETE | Admin | 删除用户 |

### 竞赛队伍 (`/api/v1/teams`)

| 接口 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/` | GET | 公开 | 获取队伍列表 |

### 权限控制示例

```python
from fastapi import APIRouter, Depends
from app.core.dependencies import require_member, require_admin

router = APIRouter()

@router.get("/member-only")
async def member_only_route(current_user = Depends(require_member)):
    return {"message": "仅 Member 可访问此接口"}

@router.get("/admin-only")
async def admin_only_route(current_user = Depends(require_admin)):
    return {"message": "仅 Admin 可访问此接口"}
```

## 核心技术栈

- **Web框架**: FastAPI 0.109.0
- **ORM**: SQLAlchemy 2.0.25
- **数据库**: MySQL（推荐 PyMySQL）
- **身份认证**: JWT (python-jose)
- **密码加密**: Passlib (bcrypt)
- **数据验证**: Pydantic
- **数据库迁移**: Alembic
- **ASGI 服务器**: Uvicorn
- **速率限制**: slowapi（防暴力破解）
