# 全局样式配置说明文档

## 📦 已安装依赖

- `tailwindcss` - 实用优先的 CSS 框架
- `postcss` - CSS 转换工具
- `autoprefixer` - 自动添加浏览器前缀
- `animate.css` - CSS 动画库（用于快速添加动画效果）

## 🎨 视觉设计规范

### 主色调
- **科技蓝**: `#2563eb` (primary-500)
- 完整色板: primary-50 到 primary-950

### 圆角规范
- **卡片圆角**: 16px (`rounded-card`)
- **按钮圆角**: 12px (`rounded-button`)
- **小组件圆角**: 8px

### 背景渐变
- `bg-gradient-cool` - 淡雅冷色调（页面主背景）
- `bg-gradient-sky` - 天空蓝渐变
- `bg-gradient-blue` - 蓝色系渐变
- `bg-gradient-primary` - 主色调渐变

## 🌟 核心样式类

### 1. 毛玻璃卡片 - `.glass-card`

```html
<div class="glass-card p-6">
  <!-- 内容 -->
</div>
```

**效果规格**:
- 背景: `rgba(255, 255, 255, 0.7)` 半透明白色
- 模糊度: `backdrop-filter: blur(12px)`
- 边框: `1px solid rgba(255, 255, 255, 0.3)` 白色半透明
- 圆角: `16px`
- 阴影: `0 8px 32px rgba(31, 38, 135, 0.15)` 柔和投影
- 悬停效果: 背景变深 + 轻微上移

**深色版本**: `.glass-card-dark`

### 2. Element Plus 样式覆盖

已全局覆盖以下组件样式：

#### 按钮 (el-button)
- 圆角: 12px
- 去除边框
- 柔和投影: `0 2px 8px rgba(0, 0, 0, 0.08)`
- 悬停效果: 投影加深 + 上移 1px
- 主要按钮: 蓝色渐变背景

#### 输入框 (el-input)
- 圆角: 12px
- 淡边框: `#e5e7eb`
- 悬停: 蓝色边框 + 柔和投影
- 聚焦: 蓝色光晕效果

#### 弹窗 (el-dialog)
- 圆角: 16px
- 去除沉重阴影，改为柔和投影
- 内边距优化: 24px

#### 其他组件
- 消息提示框 (el-message)
- 卡片 (el-card)
- 下拉菜单 (el-select-dropdown)
- 日期选择器 (el-date-picker)
- 表格 (el-table)
- 分页 (el-pagination)
- 标签 (el-tag)

## 🎬 动画配置

### Animate.css 使用

直接在元素上添加 animate.css 类名：

```html
<div class="animate__animated animate__fadeIn">淡入效果</div>
<div class="animate__animated animate__bounceIn">弹跳进入</div>
<div class="animate__animated animate__slideInUp">滑入效果</div>
```

### Tailwind 内置动画

```html
<div class="animate-fade-in">自定义淡入</div>
<div class="animate-slide-up">自定义滑入</div>
<div class="animate-scale-in">自定义缩放</div>
```

### GSAP 动画预留

已预留以下辅助类用于 GSAP 动画：

```html
<!-- 配合 GSAP 使用 -->
<div class="gsap-fade-in">初始隐藏，GSAP 控制显示</div>
<div class="gsap-slide-up">初始下移，GSAP 控制上移</div>
<div class="gsap-scale-in">初始缩小，GSAP 控制放大</div>
```

### 3D 翻转效果

```html
<div class="flip-container">
  <div class="flip-card" :class="{ flipped: isFlipped }">
    <div class="flip-card-front glass-card">
      正面内容
    </div>
    <div class="flip-card-back glass-card">
      背面内容
    </div>
  </div>
</div>
```

```javascript
onMounted(() => {

```

## 📐 设计原则

1. **一致性**: 所有圆角统一使用 12px 或 16px
2. **轻盈感**: 避免沉重的阴影，使用柔和投影
3. **层次感**: 使用毛玻璃效果营造深度
4. **流畅性**: 所有交互都有平滑过渡动画
5. **现代感**: 科技蓝色调 + 淡雅渐变背景
