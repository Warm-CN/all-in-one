## 🔐 核心功能详解

### 1. Axios 请求封装 (`src/utils/request.js`)

**✅ 自动添加 Token：**
```javascript
// 请求拦截器 - 从 localStorage 获取 Token
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

**✅ 响应拦截器 - 401 自动跳转登录：**
```javascript
// 响应拦截器
request.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // Token 过期，清除本地数据并跳转登录
      localStorage.removeItem('token')
      localStorage.removeItem('userInfo')
      router.push('/login')
    }
    return Promise.reject(error)
  }
)
```

### 2. Pinia 用户状态管理 (`src/store/user.js`)

**状态：**
- `token` - JWT Token
- `userInfo` - 用户信息（姓名、学号、角色等）

**计算属性：**
- `isLoggedIn` - 是否已登录
- `userName` - 用户姓名
- `userRole` - 用户角色
- `isAdmin` - 是否是管理员
- `isMember` - 是否是成员

**方法：**
```javascript
// 登录
await userStore.login(student_id, password)

// 获取用户信息
await userStore.getUserInfo()

// 退出登录
userStore.logout()
```

### 3. 登录页面 (`src/views/Login.vue`)

**功能：**
- ✅ Element Plus 风格的登录表单
- ✅ 学号和密码输入框
- ✅ 表单验证
- ✅ 回车键登录
- ✅ 登录成功后：
  1. 调用 `/api/v1/auth/login` 接口
  2. 将 Token 存入 `localStorage`
  3. 将用户信息存入 Pinia Store
  4. 跳转到 `/home`

**使用示例：**
```vue
<template>
  <el-form :model="loginForm" :rules="loginRules">
    <el-form-item prop="student_id">
      <el-input v-model="loginForm.student_id" placeholder="请输入学号" />
    </el-form-item>
    <el-form-item prop="password">
      <el-input v-model="loginForm.password" type="password" placeholder="请输入密码" />
    </el-form-item>
    <el-button @click="handleLogin">登录</el-button>
  </el-form>
</template>
```

### 4. 路由守卫 (`src/router/index.js`)

**✅ 自动验证登录状态：**
```javascript
router.beforeEach((to, from, next) => {
  const userStore = useUserStore()
  
  if (to.meta.requiresAuth) {
    if (userStore.isLoggedIn) {
      next() // 已登录，允许访问
    } else {
      next('/login') // 未登录，跳转登录页
    }
  } else {
    next()
  }
})
```

## 🔒 Token 存储说明

**存储位置：** `localStorage`

**存储内容：**
1. `token` - JWT Token 字符串
2. `userInfo` - 用户信息 JSON 字符串

**自动处理：**
- ✅ 登录成功自动存储
- ✅ 每次请求自动带上 Token
- ✅ Token 过期自动清除并跳转登录
- ✅ 退出登录自动清除

**手动操作：**
```javascript
// 获取 Token
const token = localStorage.getItem('token')

// 获取用户信息
const userInfo = JSON.parse(localStorage.getItem('userInfo'))

// 清除
localStorage.removeItem('token')
localStorage.removeItem('userInfo')
```

```
   ↓
8. 后端验证成功，返回 Token 和用户信息
   ↓
9. 前端保存到 localStorage 和 Pinia Store
   ↓
10. 跳转到 /home
   ↓
11. 路由守卫验证通过，显示首页
```

## 🛠️ 常见问题

### 1. 跨域问题
**解决方案：** 已在 `vite.config.js` 配置代理

### 2. Token 过期
**自动处理：** 响应拦截器检测到 401 后自动跳转登录页

### 3. 刷新页面后登录状态丢失
**已解决：** Token 存储在 localStorage，刷新页面会自动恢复

### 4. 如何添加新的 API 接口
```javascript
// src/api/booking.js
import request from '@/utils/request'

export function getBookings() {
  return request({
    url: '/api/v1/bookings/my-bookings',
    method: 'get'
  })
}
```
